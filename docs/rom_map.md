# ROM map: Dragon Ball Z: The Legacy of Goku (USA), ALGE

8 MB (0x800000 bytes, 0x7A6418 used), SHA-1 `a3c8c76742f11fc6a3f6e3fcca20992458cac0b5`.
Offsets are ROM file offsets; add 0x08000000 for the bus address.
The byte-level classification (100% coverage) is `config/regions.yaml`, generated by `tools/bfdis/regions.py`.
Layout constants are in `config/game.json` (read by `tools/bfdis/game.py`) and `tools/assets/const.py`.

There is no RW image: the game copies two routines into IWRAM itself (`IntrMain` from 0x08000138 to 0x03003BC0 and an ARM
routine from 0x08008840 to 0x03003D70).
